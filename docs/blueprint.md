# **App Name**: LeadFlow

## Core Features:

- Automatic Lead Capture: Integrate webhooks or APIs with landing pages, WhatsApp, Facebook Ads, IVR, and website forms. Auto-populate CRM with incoming leads in real time. Tag source of lead (e.g., ", Website Form", ", Facebook Ad", ", Walk-in").
- Lead Filtering and Assignment: Filter leads based on parameters: source, location, inquiry type, treatment interest. Rule-based assignment engine (e.g., assign walk-ins to front desk, IVF leads to counselor). Manual override option for reassignment.
- Patient Profile Hyperlinking: Hyperlink patient name across CRM to open a dedicated profile view. Include patient photo, contact info, lead source, history, and timeline.
- Patient Journey Tab: Tabular layout showing: Date-wise actions taken (call, message, appointment). Stage updates (e.g., "Initial Inquiry" → "Consultation Done"). Visit history, tags (e.g., “High Intent”, “Needs Follow-up”), and journey score.
- Actionable Patient Management: Enable staff to: Mark as “No Go” (disqualified). Schedule follow-ups (with reminder alerts). Book appointments directly from CRM. Update visit status (e.g., “Walk-in Done”, “Procedure Booked”).
- Task & Follow-Up Calendar: Central calendar view with: Scheduled follow-ups, callbacks, appointments. Drag-and-drop rescheduling. Color-coded lead status (pending, done, overdue). Daily/weekly/monthly views.
- Automated Follow-Up Sequences: Predefined sequences triggered on lead capture: Day 1: SMS, Day 2: WhatsApp, Day 3: Call Reminder. Allow user-defined sequences per lead type.
- Internal Notes & Team Mentions: Add lead-specific internal comments. Use “@user” tagging to assign internal tasks or escalate. View all past notes with timestamps.
- Lead Source & Conversion Reports: Charts & tables showing: Lead volume by source. Conversion rate by counselor. Average response time. Follow-up success rate.
- Document Upload & Request System: Upload patient documents (e.g., scans, IDs, consent forms). Send document request links to patients via SMS/WhatsApp. Secure storage with download logs.
- Custom Pipeline Views: Create and manage pipelines like: General OPD, IVF Journey, Surgery Consultation. Kanban-style cards for each lead, movable across stages.
- Role-Based Access Control: Define user roles (Admin, Receptionist, Counselor, Doctor). Limit access to leads, reports, actions based on role. Prevent data leakage by blocking export for restricted roles.
- Audit Trail & History Logs: Track who did what: Lead assignment, Status changes, Appointment bookings. Timestamped logs accessible to admins.
- Duplicate Lead Detection: Smart detection using phone number, email, name. Merge duplicate profiles without data loss.
- Mobile-Responsive CRM: Mobile-friendly interface or dedicated app for: Field counselors, Front desk agents, Doctors
- Lead Import & Export: Import bulk leads from CSV with mapping options. Export filtered leads for offline campaigns or analytics.
- Configurable Tags & Statuses: Admin can define custom: Lead tags (e.g., “High Priority”, “Requires Translation”). Status stages (e.g., “New”, “Consultation Booked”, “Treatment Done”).
- Consent Management for Marketing: Capture marketing opt-in during lead entry. Tag leads who give permission for WhatsApp/email. Separate contact lists for compliant outreach.
- Appointment Booking Integration: Book appointments directly from the lead card. Sync with Doctor's schedule/calendar module. Send SMS/WhatsApp confirmation to patient.
- Missed/Overdue Follow-Up Alerts: System reminders for: Overdue callbacks, Missed appointments, No action on a lead for X days

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and trust.
- Background color: Light gray (#F0F2F5) for a clean and modern interface.
- Accent color: Teal (#009688) to highlight important actions and elements.
- Body and headline font: 'Inter' sans-serif font for a clean, modern, and readable experience.
- Use flat, minimalist icons to represent actions and categories.
- Employ a card-based layout for patient profiles and tasks to maintain clarity and organization.
- Implement subtle transitions and animations to enhance user interaction.
